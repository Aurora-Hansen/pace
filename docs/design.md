## **1\. Navneforslag**

* **Pace:** (Vinnerforslag) Et kort, moderne navn som handler om å finne sitt eget tempo i studiene.  
* **StudieFlyt / Flyt:** Spill på begrepet *flow state* – å komme i sonen uten å bli overveldet.  
* **Kollokvie:** Varmt og velkjent for målgruppen, signaliserer struktur og god oversikt.

## **2\. Visuell Identitet**

### **Fargepalett (Hex)**

Paletten er satt sammen for å virke beroligende fremfor stressende, med en frisk aksentfarge som motiverer.

* **Primærfarge:** \#2E5B88 (*Dyp Harmoniblå*) – Gir trygghet, fokus og struktur.  
* **Aksentfarge:** \#FF8C61 (*Varmerød / Korall*) – Brukes til viktigste knapper, fremgang og overbelastningsvarsler.  
* **Bakgrunn (Flate):** \#F8FAFC (*Kritthvit/Lys grå tone*) – Myk bakgrunn som er skånsom for øynene.  
* **Kort/Innhold:** \#FFFFFF (*Ren hvit*) – Bakgrunner for to-do-kort og kalenderelementer.  
* **Tekst (Mørk):** \#1E293B (*Mørk skifergrå*) – Skarp lesbarhet uten den harde kontrasten av ren sort.  
* **Advarsel / Flaskehals:** \#EF4444 (*Myk Rød*) – Vises når oppgaver hoper seg opp og tidsfrister er i fare.

### **Mørk modus**

Samme ro og samme aksent, med mørke flater. Kortene bruker den lyse paletten sin tekstfarge, og primærfargen er lysnet så den kan leses på mørk bakgrunn.

* **Bakgrunn (Flate):** \#0F172A (*Dyp skifer*)
* **Kort/Innhold:** \#1E293B (*Mørk skifergrå*, samme som lys tekst)
* **Tekst (Lys):** \#E2E8F0 (*Lys skifer*)
* **Primærfarge:** \#7BA7D4 (*Lysere harmoniblå*) – lenker, aktiv fane og knapper med mørk tekst (\#0F172A)
* **Aksentfarge:** \#FF8C61 (*Varmerød / Korall*) – uendret, med mørk tekst
* **Advarsel / Flaskehals:** \#F87171 (*Lysere rød*)

Kontrast (WCAG AA krever 4,5:1 for tekst og 3:1 for grafikk), målt med avledede farger slik de brukes i appen:

| Kombinasjon | Kontrast |
| --- | --- |
| Tekst på kort | 11,9:1 |
| Dempet tekst på kort | 6,9:1 |
| Primær på kort | 5,8:1 |
| Primær på aktiv fane (primær 12 % på kort) | 4,7:1 |
| Mørk tekst på primærknapp | 7,1:1 |
| Mørk tekst på aksentknapp | 7,8:1 |
| Advarsel som markering på kort | 5,3:1 |

Illustrasjonene har mørkeblå streker som forsvinner mot mørk bakgrunn. I mørk modus står de derfor på en lys, avrundet flate, og hero-bildet på landingssiden dempes litt og får en mørk overgang bak teksten.

* **Overskrifter:** **Plus Jakarta Sans** (Vekt 600 / 700\) – En moderne, imøtekommende og ryddig sans-serif som gir et friskt og profesjonelt inntrykk.
